## rig-vertexai

This companion crate integrates VertexAI / Google AI Platform.

## Usage

Add the companion crate to your `Cargo.toml`, along with the rig-core crate:

```toml
[dependencies]
rig-vertexai = "0"
rig-core = "0"
```

You can also run `cargo add rig-vertexai` to add the most recent versions of the dependencies to your project.

See the [`/examples`](./examples) folder for usage examples.
